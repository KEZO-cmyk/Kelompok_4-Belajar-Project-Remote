ALUR KERJA REGRESI LINEAR

Teknik regresi linier sederhana mencoba untuk menyusun grafik garis antara dua variabel data, yaitu X dan Y. Sebagai variabel independen, (X) berada di sepanjang sumbu horizontal sebagai predictor dan variabel dependen (Y) berada pada sumbu vertikal sebagai variabel repons atau variabel yang diprediksi.

Langkah-langkah dalam regresi linier

1. Menentukan Variabel dan Persamaan Dasar

  • Tentukan variabel

    • Identifikasi variabel dependen (Y) sebagai target angka yang ingin diprrediksi (misalnya harga rumah), dan variabel independen atau fitur (xi) sebagai faktor penentunya (misalnya luas banguan).

  • Susun persamaan linear

    • Model mencari garis atau bidang paling pas dengan persaan:

    Y = β0 + β1X1 + β2X2 + ... + βpXp + ε

    Keterangan:
    β0 adalah intercept/bias, βi adalah bobot/koefisien fitur, dan ε adalah error yang tidak dapat dimodelkan.

2. Memulai dari Model Awal (Baseline) dan Mengukur Error

  • Buat garis awal sederhana

    • Sebagai titik awal, garis prediksi bisa ditarik datar menggunakan nilai rata-rata dari data Y (dengan mengasumsikan bobot β1 = 0).

  • Hitung residual (error)

    • Ukur selisih jarak antara setiap titik data aktual (Yi) dengan garis prediksi (Ŷi). Tujuannya adalah memperkecil error ini sekecil mungkin.

3. Memilih Metrik Evaluasi (Loss Function)

  • Tentukan cara mengukur performa model.

    • Dua metrik utama yang menjadi sorotan untuk mengevaluasi seberapa pas garis regresi terhadap data:

    • Mean Squared Error (MSE): Rata-rata kuadrat dari selisih antara nilai aktual dan prediksi.
    • Root Mean Squared Error (RMSE): Akar kuadrat dari MSE, memberikan error dalam satuan yang sama dengan data asli.
    • Alternatif lain: Mean Absolute Error/MAE jika ingin error diukur secara linear tanpa menghukum outlier secara berlebihan

4. Mencari Koefisien Terbaik (Learning the Coefficients)

Untuk menemukan nilai koefisien (β̂0, β̂1, ... ) yang meminimalkan error (MSE/RSS), ada dua pendekatan utama yang digunakan:

  • Gradient Descent (Solusi Iteratif)

    • Algoritma optimasi yang memperbarui nilai bobot/koefisien sedikit demi sedikit secara berulang (iteratif) hingga error mencapai titik minimum. Metode ini paling sering dipakai di machine learning karena efisien untuk data dengan banyak fitur.

  • Normal Equation (Solusi Matematis Langsung/Closed Form)

    • Menghitung koefisien secara langsung menggunakan rumus aljabar matriks:

    β̂ = (XTX)-1XTY

    Metode ini cepat untuk fitur sedikit, tetapi jarang dipakai pada dataset besar karena proses invers matriks membutuhkan komputasi berat.

5. Melakukan Prediksi (Inference) dan Interpretasi

  • Masukkan data baru ke persamaan

    • Setelah koefisien terbaik ditemukan, prediksi nilai masa depan (Ŷ) dilakukan dengan memasukkan angka fitur baru (Xi) ke persamaan:
    Ŷ = β̂0 + β̂1X1 + ... + β̂pXp

  • Pahami arti koefisien

    • Setiap nilai (β̂i) menunjukkan seberapa besar perubahan rata-rata nilai (Y) jika fitur (Xi) bertambah satu satuan (dengan asumsi fitur lain tetap).

6. Memeriksa Validitas dan Asumsi Model

  • Evaluasi keadaan koefisien dan asumsi

    • Dalam konteks statistik, praktisi emeriksa standard error, p-value, serta asumsi dasar regresi (linearitas, independensi error, homoskedastisitas, dan normalitas error).

  • Uji generalisasi

    • Dalam konteks machine learning, langkah terpenting adalah menguji model pada test dataset untuk memastikan model mampu memprediksi data baru dengan akurat (generalisasi yang baik).

Jika asumsi dilanggar dan performa buruk, data perlu ditransformasi atau model perlu diperluas.
